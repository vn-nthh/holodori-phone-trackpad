## Faster AOA transport with automatic USB compatibility

The Windows setup now offers two default-checked USB options:

- **WinUSB low-latency data support** pre-stages device-specific packages for
  Android Accessory `18D1:2D00` and interface 0 of `18D1:2D01`.
- **UsbDk handshake and fallback support** switches the phone into accessory
  mode without replacing its normal MTP driver and remains available as the
  compatible data backend.

Holodori prefers WinUSB for the live input stream. If the WinUSB option was
unchecked, its package could not be installed, or Windows cannot open the
interface, the app now switches to UsbDk automatically. The installer never
binds WinUSB to the phone's normal MTP or ADB interfaces.

### Transport improvements

- Two ordered overlapped WinUSB reads stay preposted in reusable buffers,
  reducing the gap between USB completions and avoiding a fresh receive-buffer
  allocation for every read.
- Android reports queue age and depth, warns at 8 ms, resynchronizes at 25 ms,
  and retains the old 100 ms threshold as an ultimate failsafe.
- Benchmark builds use the highest-resolution MotionEvent timestamp available
  and report clock-normalized excess delay so sub-millisecond transport
  differences can be compared across the phone and PC clocks.
- The Android companion version is now 0.1.3.

The WinUSB provisioning helper is built from libwdi 1.5.1. Its LGPL source,
build patch, and Microsoft redistributable notices are included with the
installed application.
