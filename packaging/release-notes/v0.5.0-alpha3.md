# Doritrack v0.5.0-alpha3 — experimental Windows V5 startup fix

Fixes `v5 network: An invalid argument was supplied. (os error 10022)` when
starting V5 pairing or a remembered connection on Windows. The host now enables
the socket interface filter before adding the selected USB/local-network
adapter. Interface confinement and authenticated V5 input remain enforced.

Includes alpha2's missing USB-adapter recovery fix and Wi-Fi UI changes:
legacy protocol and phone-internet options are shown only for USB.

## Downloads

- Windows x64: extract `Doritrack-v0.5.0-alpha3-windows-x64.zip` and open
  `HolodoriUsbController.exe`.
- Linux x64: extract `Doritrack-v0.5.0-alpha3-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`. Linux networking behavior is unchanged.
- Android: `Doritrack-v0.5.0-alpha3-android.apk`, version code 28.

**No Android update is needed for this fix.** Existing V5 phone apps remain
compatible. The optional APK uses the same experimental signing key as alpha2,
which differs from published alpha1. Updating an alpha1 installation requires
uninstalling it first and loses settings/pairing; keep that phone app to avoid
the reset.

## Validation and limits

The Windows socket regression test uses the production listener setup and
verifies received data and its ingress interface. The published alpha2 binary
reproduced error 10022 on the development PC; the corrected binary successfully
entered Wi-Fi pairing discovery on the same adapter.

Release checks cover native tests, strict Clippy, optimized builds, launcher
frontend/Rust checks, Android debug/release builds and lint, and isolated V4/V5
loopback fault checks against 8.333 ms. Loopback uses simulated OS acceptance;
physical phone/router/PC and USB gameplay soaks remain untested. This is an
unofficial companion, subject to the game's terms and competitive rules.
