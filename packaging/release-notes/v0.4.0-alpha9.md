# Holodori Phone Trackpad v0.4.0-alpha9

This is an experimental Windows + Android build for testing lossless touch
transport and native Windows Touch delivery.

## Included

- `HolodoriLosslessTouch-v0.4.0-alpha9-windows-x64.zip`
- Windows native Rust host with `touch` and `keys` modes
- Independent `WM_POINTER` receiver and local touch-injection smoke test
- Android APK speaking acknowledged duplex AOA protocol v4
- UsbDk installer, checksums, run scripts, and protocol documentation

## Important

- This build is not wire-compatible with the stable v0.2.1 Python host.
- Install the Android APK as a separate experimental build; it is debug-signed.
- Use a Windows 10/11 PC, an Android phone, and one USB data cable.
- Touch mode must be verified with the included independent probe before use
  with Holodori.
- Protocol reliability covers USB-session transport loss and replay; unplugging
  the cable starts a new session and does not replay stale gameplay.

See `README.txt` inside the ZIP for installation, smoke-test, and diagnostics
instructions.
