# Doritrack v0.5.0-alpha7 — launcher polish and USB tethering shortcut

Small follow-ups to the alpha6 interface.

- The Windows launcher now always starts as administrator. Windows asks once
  when it opens; the native host it launches inherits that, so keys reach a game
  that runs as administrator and USB-tether route recovery never needs the old
  mid-session "Restart as admin" detour.
- The launcher window is resizable again. Content stays centred at its design
  width.
- The preferences button is a cog. The previous glyph read as a sun and looked
  like a light/dark toggle.
- Preferences rows have one divider each; the doubled line under the latency
  report row is gone.
- The Android Pair and Ready screens show "USB tethering must be on. Open
  settings" whenever USB is selected. Tapping it opens the phone's tethering
  page, falling back to the network settings page on phones that hide it.

## Downloads

- Windows x64: extract `Doritrack-v0.5.0-alpha7-windows-x64.zip` and open
  `HolodoriUsbController.exe`. Accept the administrator prompt.
- Android: `Doritrack-v0.5.0-alpha7-android.apk`, version code 32.
- Linux x64: extract `Doritrack-v0.5.0-alpha7-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`.

No protocol, host, or transport code changed. Alpha5 and alpha6 APKs remain
protocol-compatible; pairings and preferences carry over.

## Validation and limits

Release validation covers native tests, strict Clippy, optimized builds,
Android unit tests, debug/release builds and lint, launcher frontend/Rust
checks, and V4/V5 loopback fault recovery against the 8.333 ms budget. The
embedded Windows manifest was checked for `requireAdministrator`.

The tethering shortcut relies on the phone exposing the standard tethering
settings action; some OEM builds land on the broader network page instead.
Physical USB/Wi-Fi gameplay soaks remain pending. Keyboard mode is the current
gameplay baseline; touch mode is a proof of concept. This is an unofficial
companion subject to the game's terms and competitive rules.
