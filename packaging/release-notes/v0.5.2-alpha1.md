# Doritrack v0.5.2-alpha1 — Same-lane tap spacing (beta)

Prerelease on top of v0.5.1. Install the Windows and Android apps from this
same release.

## Separate fast same-lane taps (beta, off by default)

A game that reads key state once per rendered frame can miss a release and
re-press of the same lane when both reach Windows inside one game frame — for
example two fingers alternating quickly on one lane, or several taps delivered
together after a short network repair. A second finger landing on a lane that
another finger already holds was also only a repeated key-down, which games
ignore.

Turn on **Settings > Separate fast same-lane taps (beta)** in the PC app to
keep each of these visible to the game:

- A re-press of a lane waits until 17 ms after that lane's release.
- A finger landing on a lane another finger holds sends a release, then a
  press 17 ms later.
- The release after a finger-down press is held for at least 17 ms, so a tap
  delivered in one burst is not invisibly short.
- Slides are not delayed, and a slide still never leaves a moment with no key
  held. Ordinary taps on different lanes are unaffected.

Only those same-lane cases are delayed, by up to about one 60 Hz frame. Please
report whether fast same-lane patterns register better with the option on or
off; the default may change based on that feedback.

## Reliability and latency

- **Windows timer precision.** The PC host requests a 1 ms timer period while
  it runs, so its stuck-key watchdog and recovery timing are no longer
  stretched to Windows' default 15.6 ms tick. Host reports record whether it
  was granted and a measured 1 ms socket wait.
- **Wi-Fi priority.** The phone marks its V5 traffic as DSCP EF, which most
  routers send in the Wi-Fi voice queue. Phone reports show
  `qos_request=dscp_ef` and the socket traffic class readback.
- **Stuck-key safety net.** If the PC controller is killed or crashes, the PC
  app now releases all six lane keys. Windows otherwise keeps injected keys
  held after the process dies.

## Downloads

- Windows x64: `Doritrack-v0.5.2-alpha1-windows-x64.zip`.
- Android: `Doritrack-v0.5.2-alpha1-android.apk`, version code 39. It updates
  v0.5.1 in place, keeping settings and pairing.

Automated loopback testing kept healthy delivery and recovery after loss of
both immediate copies within the 8.333 ms design budget. These tests simulate
OS acceptance; the beta tap spacing has not yet been verified against the game
on every PC, and physical latency depends on your phone, cable or router, and
PC.
