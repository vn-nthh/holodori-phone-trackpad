# Holodori USB-tethered UDP v0.4.1-alpha2

This experimental pre-release fixes stale touch delivery after an active
USB-tethered UDP/RNDIS data-path stall.

## Highlights

- Discovery ACKs no longer mask a stalled active data/ACK connection.
- Active-session timeout checks now run even while discovery packets continue
  arriving.
- Stale queued touch frames are discarded after the existing host timeout so
  recovered UDP traffic cannot inject seconds-old input.
- The Windows ZIP and Android APK are published as separate release assets.

## Validation

- Native Rust tests: 18 passed.
- Android debug and release builds completed successfully.
- Optimized native host build completed successfully.

The Android APK remains debug-signed for experimental testing.
