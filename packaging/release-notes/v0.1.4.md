## More forgiving controls and clearer recovery

This release makes the phone play surface easier to hit, brings the AOA
editor in line with the legacy ADB editor, and adds clearer recovery when a
USB connection does not complete normally.

### Forgiving play zones

- Touches beyond the left and right edges now map to the first and last lanes.
- Touches above or below the drawn keys still register in the corresponding
  lane.
- The behavior is consistent across both AOA and ADB transports.
- Lock and fullscreen controls remain excluded from gameplay input.

### Matching AOA and ADB editors

- Drag inside the play zone to move it.
- Drag a side handle to stretch only that axis while the opposite edge stays
  fixed.
- Drag a corner handle to resize and rotate while the opposite corner stays
  fixed.
- The Android companion app is now version 0.1.4 with version code 5.

### Connection Doctor

- Connection status now distinguishes an open USB transport from a ready
  controller and waits for a valid touch packet before reporting success.
- Stable `HPT-...` codes pair connection failures with concrete recovery
  actions.
- Run with `--diagnose` for a live stage view. Use `report` for a
  privacy-preserving diagnostic summary or `retry` to restart discovery
  without relaunching the app.
- Disconnects and manual retries release held keys before reconnecting.

### Safer legacy ADB transport

- Touch frames are applied atomically, preserving chords and gap-free lane
  transitions.
- Unlocking the phone editor releases held keys. Fingers already touching
  when play mode is restored must lift before they can press again.
- Cleanup is retryable and ownership-aware, so it does not remove another
  process's ADB reverse mapping or overwrite phone settings changed during the
  session.
- The raw input loop uses larger binary reads and avoids per-event text
  decoding to reduce processing overhead.

Existing play-zone settings remain compatible. Install both the updated
Windows package and Android APK to get the complete v0.1.4 behavior.
