## A cleaner default play mode

The PC touch overlay is now off by default, so Holodori Phone Trackpad stays out of the way while you play.

If you want the live fingertip visualizer, launch **Holodori Phone Trackpad (with Touch Overlay)** from the Start menu. You can also run the app with `--overlay`.

### Included

- Updated Android companion app to version 0.1.2.
- `--overlay-edit` still opens the overlay directly in position and resize mode.
- `--no-overlay` remains available for scripts and shortcuts that explicitly keep the visual layer off.
