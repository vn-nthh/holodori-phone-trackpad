# Doritrack v0.5.0-alpha6 — new launcher and phone app interface

Both apps were rebuilt around one screen per setup step. You choose how the
phone is connected, pair once, then Start. Pair and Start never appear together:
a phone that has not paired cannot reach Start, and a paired phone goes straight
to it. Preferences (key slots, latency report, phone-internet tethering, protocol
v4, thumb mode, forgetting the paired device) live behind a gear button instead
of the main flow. Host and transport messages are shown as short status lines,
with the underlying detail only when something needs your attention.

A shared USB / Wi-Fi link illustration replaces the old status text. It animates
while searching and pulses while connected, cross-fades when you switch
transports, and stays still when the system asks for reduced motion. The whole
interface uses one muted ink palette with no gradients.

The Android app is now titled Doritrack. Its setup screens follow the same
steps as the launcher, the pairing lanes show "Step N of 8", and the pad reports
Connected / Looking for your PC / Reconnecting instead of transport diagnostics.

## Downloads

- Windows x64: extract `Doritrack-v0.5.0-alpha6-windows-x64.zip` and open
  `HolodoriUsbController.exe`.
- Android: `Doritrack-v0.5.0-alpha6-android.apk`, version code 31.
- Linux x64: extract `Doritrack-v0.5.0-alpha6-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`.

No protocol, host, or transport code changed. The alpha5 APK remains
protocol-compatible; existing pairings and preferences carry over.

## Validation and limits

Launcher frontend tests cover screen derivation from host state, pairing stage
progression, status copy, and the illustration markup. Release validation covers
native tests, strict Clippy, optimized builds, Android unit tests, debug/release
builds and lint, launcher frontend/Rust checks, and V4/V5 loopback fault
recovery against the 8.333 ms budget.

This is an interface release. It does not change input timing, pairing
security, or gameplay behaviour, and it does not claim to fix rapid-tap misses.
Physical USB/Wi-Fi gameplay soaks remain pending. Keyboard mode is the current
gameplay baseline; touch mode is a proof of concept. This is an unofficial
companion subject to the game's terms and competitive rules.
