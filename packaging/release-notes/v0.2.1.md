## Slide notes no longer skip lanes

Android can bundle several finger positions into one touch update. Holodori
previously used only the newest position, so a fast slide could jump over a
lane even though the USB connection had not dropped anything.

### What was fixed

- Every bundled touch position is now played back in order.
- Repeated movement inside one lane can still be combined for speed, but a
  lane crossing is never combined away.
- The phone now uses the same lane count as the PC, including custom layouts.
- The phone's drawing work is kept out of the touch-sending path and limited
  separately, so visuals cannot hold up gameplay input.
- The Android release is optimized and includes a startup/input performance
  profile.

### Clearer troubleshooting

- Queue incidents now show where time was spent: Android input dispatch, app
  handling, the writer queue, USB, and host delivery.
- Reports show whether Android bundled touch history and how many lane
  crossings were preserved.
- Benchmark summaries keep the important averages, peaks, percentiles, and
  counts with shorter wording.

### Updating

Install both the v0.2.1 Windows package and v0.2.1 Android APK to get the slide
fix and matching diagnostics. Existing play-zone settings remain compatible.

If Android refuses to install the APK over v0.2.0, uninstall the old phone app
once and then install v0.2.1. Some older automated APKs used a temporary signing
certificate; uninstalling clears the phone's saved play-zone position, so it
will need to be set again.

The Android companion app is version 0.2.1 with version code 7.
