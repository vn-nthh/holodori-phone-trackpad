# Doritrack v0.5.0

The first stable protocol V5 release brings authenticated USB and Wi-Fi input,
first-use lane-pattern pairing with approval on the PC, and remembered sessions.
Install the Windows and Android apps from this same release.

- Choose USB tethering or a private local network before pairing and starting.
- Use the phone's adjustable play area or thumb mode for taps, holds, slides,
  and chords across the six keyboard lanes.
- Includes the alpha-series input recovery, overlapping tap, Android USB
  detection, and setup-screen improvements.
- Adds the new phone and PC logos, adaptive Android launcher icons, and Windows
  executable, taskbar, and Alt+Tab icons.
- Signs Android releases with a persistent private release key, with signature
  checks in the packaging workflow.
- Updates the English and Japanese setup instructions for V5.

## Downloads and upgrade

Extract `Doritrack-v0.5.0-windows-x64.zip` and run `HolodoriUsbController.exe`.
Install `Doritrack-v0.5.0-android.apk` on the phone.

**Upgrading from an alpha or v0.4.1:** uninstall the old Android app once before
installing this APK, because the release signing key differs from the old debug
key. Uninstalling clears the phone app's settings and pairing; pair again after
installation. Future releases signed with this key can update normally.

The Windows launcher asks for administrator access when it starts. Linux remains
available from source using `LINUX_SETUP.md`.

The design target is one 120 Hz frame (8.333 ms). Automated loopback checks do
not establish latency on every phone, cable, router, PC, or game input loop.

This is an unofficial community tool, subject to the game's terms and
competitive rules.
