# Doritrack v0.5.1-alpha2 — Windows packaging update

This prerelease separates the Windows and Android downloads, prepares the PC
app for Microsoft Store submission through MSIX, and updates the app artwork.

- The portable Windows ZIP now contains only the Windows launcher, native host,
  documentation, and support files. Download the Android APK separately.
- Adds validated MSIX packaging with a clearly marked test identity for alpha
  builds. Store production packages remain stable-only and require the identity
  assigned after the app name is reserved in Partner Center.
- Moves Windows reports to `%LOCALAPPDATA%\Doritrack\Logs`; an installed MSIX
  uses its package `LocalState\Logs` directory. Use **Open report folder** in
  Settings after Stop.
- Replaces the Android launcher icon and Windows taskbar icon, and prepares a
  separate 300 x 300 logo for the Microsoft Store listing.

## Downloads

- Windows x64: extract `Doritrack-v0.5.1-alpha2-windows-x64.zip` and run
  `HolodoriUsbController.exe`.
- Android: install `Doritrack-v0.5.1-alpha2-android.apk`, version code 36.

The MSIX produced for this alpha uses a development identity and is retained as
a CI validation artifact. It is unsigned and is not a public installer or Store
submission.

Automated loopback testing kept healthy delivery and recovery after loss of
both immediate copies within the 8.333 ms design budget. These tests simulate
OS acceptance and do not establish latency on every phone, cable, router, PC,
or game input loop.

This is an unofficial community tool, subject to the game's terms and
competitive rules.
