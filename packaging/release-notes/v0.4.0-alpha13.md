# Holodori USB-tethered UDP v0.4.0-alpha13

This is an experimental, driver-free USB-tethered release.

## Highlights

- Replaced the heavy WinUI launcher with a compact Tauri Windows app.
- The normal GUI now contains only lane keys, USB port, latency-report choice,
  and Start/Stop controls.
- The GUI always starts keyboard-lane mode with the 8.333 ms 120 Hz warning
  budget; touch demonstration controls and threshold editing are hidden.
- The Tauri launcher and Rust host are shipped together in the portable folder.
- No ADB, root, AOA, UsbDk, WinUSB, or custom driver is included or used.

## Runtime note

The launcher uses the Microsoft Edge WebView2 runtime provided by supported
Windows 10/11 installations. It is not bundled into this lightweight release;
the fixed WebView2 runtime is a much larger optional deployment mode.

The Android APK remains debug-signed for experimental testing.
