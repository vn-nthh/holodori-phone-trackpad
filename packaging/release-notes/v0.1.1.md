## One-download Windows setup

The new `HolodoriPhoneTrackpadSetup.exe` installs both Holodori Phone Trackpad and the USB support needed for its normal Android Open Accessory connection. There is no longer a separate UsbDk download to find.

During setup, leave **Install UsbDk USB connection support** selected unless you already use a WinUSB-bound Android Accessory interface. Windows will request administrator permission, and may ask you to restart once so the USB driver can attach.

### Also included

- Updated Android companion app to version 0.1.1.
- The standalone `HolodoriPhoneTrackpad.exe` remains available for portable/manual installs.
- UsbDk is distributed as its signed upstream 1.0.22 x64 installer, with its Apache-2.0 license included in the app installation.

## Upgrade notes

- If UsbDk is already installed, setup detects it and does not run the driver installer again.
- Updating or reinstalling Holodori does not require reinstalling UsbDk.
- Uninstalling Holodori intentionally leaves UsbDk installed, since it is a shared Windows USB driver. It can be removed separately from Windows Settings if no longer needed.
