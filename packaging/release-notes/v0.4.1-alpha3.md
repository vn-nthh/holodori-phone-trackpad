# Holodori USB-tethered UDP v0.4.1-alpha3

This experimental pre-release hardens UDP loss recovery and prevents held
input from surviving a stalled or failed transport path.

## Highlights

- Every frame, discovery record, and acknowledgement has immediate redundant
  coverage, with a 2 ms replay path for a pair of lost datagrams.
- Android uses a bounded active-link watchdog, retains stationary contact
  snapshots across socket restarts, and recovers with a 4 ms initial backoff.
- Windows releases held keyboard/touch input on heartbeat silence, socket
  failure, acknowledgement-write failure, launcher EOF, and shutdown.
- Host parsing rejects malformed actions, duplicate pointer IDs, and far-future
  reorder floods without allowing continuous junk to stall timeout handling.
- The launcher reports a fixed UDP-port conflict before starting a second host.

## Validation

- Native Rust tests: 25 passed; strict Clippy and optimized build passed.
- Android debug/release builds and debug/release lint passed.
- Tauri frontend, tests, strict Clippy, and optimized Windows build passed.
- Legacy Python tests: 110 passed.
- Release-host fault injection recovered a corrupt/lost copy in 0.124 ms and a
  two-copy loss with 2 ms replay in 2.091 ms on loopback.

The Android APK remains debug-signed for experimental testing. The 8.333 ms
target still depends on the physical phone, cable, Windows scheduler, and
RNDIS path; a real-device soak is required before treating it as universal.
