# Holodori USB-tethered UDP v0.4.1-alpha1

This is an experimental pre-release focused on long-session stability and UDP
transport efficiency.

## Highlights

- Idle phone sessions no longer emit synthetic 125 Hz heartbeat traffic.
- Active stationary contacts retain the 8 ms Windows touch refresh cadence.
- Android reuses UDP control buffers, CRC state, and datagram wrappers to
  reduce allocation and garbage-collection pressure.
- The Windows host decodes each UDP datagram directly instead of routing it
  through the legacy stream parser.
- Metrics reports now include heartbeat-frame counts for long-session analysis.
- No ADB, root, AOA, UsbDk, WinUSB, or custom driver is included or used.

## Validation

- Native Rust tests: 18 passed.
- Android debug build and optimized native host build completed successfully.

The Android APK remains debug-signed for experimental testing, and the 120 Hz
latency budget still depends on the phone, cable, and RNDIS network path.
