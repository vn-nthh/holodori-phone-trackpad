# Doritrack v0.5.1-alpha1 — lower-latency scheduling

This prerelease reduces scheduling and feedback overhead for authenticated V5
sessions while preserving durable, ordered input delivery.

- Android 10 and newer requests Wi-Fi low-latency mode during V5 Wi-Fi pairing
  and play, then releases the request when the binding closes.
- Windows requests HighQoS alongside the existing high input priority so the
  host opts out of execution-speed throttling when the OS permits it.
- The host sends two ACK copies when accepted input advances and one ACK for a
  duplicate or ordering hole, keeping loss recovery immediate with less traffic.
- Adds a privacy policy describing local controller data, pairing credentials,
  diagnostics, and the new Wi-Fi lock permission.

## Downloads

- Windows x64: extract `Doritrack-v0.5.1-alpha1-windows-x64.zip` and run
  `HolodoriUsbController.exe`.
- Android: install `Doritrack-v0.5.1-alpha1-android.apk`, version code 35.
- Linux x64: extract `Doritrack-v0.5.1-alpha1-linux-x64.tar.gz` and follow
  `LINUX_SETUP.md`.

Automated loopback testing kept healthy delivery and recovery after loss of
both immediate copies within the 8.333 ms design budget. These tests simulate
OS acceptance and do not establish latency on every phone, cable, router, PC,
or game input loop.

This is an unofficial community tool, subject to the game's terms and
competitive rules.
