## Stable latency across long and restarted sessions

This release keeps AOA input responsive during long play sessions and prevents
an Android transport left open by an older PC process from contaminating the
next session.

### Clean host-session lifecycle

- Touch protocol v2 gives every PC process an explicit transport epoch.
- Android clears queued touches and diagnostics when a new host process
  attaches to an already-running phone session.
- The PC ignores records from the previous host until Android sends the new
  session-reset marker.
- Recovery resets held input and scopes queue and benchmark statistics to the
  active transport epoch.
- Session summaries now report host recoveries separately from queue warnings,
  resynchronizations, and failsafes.

### Stable long-session performance

- The AOA benchmark corrects phone-to-PC clock drift using a bounded rolling
  60-second window, so longer sessions no longer inflate maximum latency.
- Touch overlay updates use a latest-state mailbox instead of an unbounded
  queue, preventing UI work from accumulating behind the live input stream.
- Benchmark output distinguishes recent samples from the total records seen in
  the current session.

### Compatibility

Touch protocol v2 is not compatible with older PC or Android builds. Install
both the v0.2.0 Windows package and v0.2.0 Android APK before reconnecting.
Existing play-zone settings remain compatible.

The Android companion app is version 0.2.0 with version code 6.
