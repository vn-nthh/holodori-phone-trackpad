# Holodori USB-tethered UDP v0.4.0

This is a driver-free USB-tethered Windows/Android release. It is marked as a
GitHub prerelease because the 120 Hz latency budget is not guaranteed for
every individual sample on every phone/cable/RNDIS path.

## Highlights

- Compact Tauri Windows launcher with a blackout dark interface.
- Native Windows minimize, maximize, and close actions remain available; the
  caption is black, blank, and has no application logo.
- The GUI contains only lane keys, USB port, latency-report preference, and
  Start/Stop controls.
- The GUI always starts keyboard-lane mode with the 8.333 ms 120 Hz warning
  budget; touch demonstration controls and threshold editing are hidden.
- The portable folder includes the Tauri launcher, native Rust host, Android
  APK, diagnostics probes, documentation, and checksums.
- No ADB, root, AOA, UsbDk, WinUSB, or custom driver is included or used.

## Benchmark note

The latest 207.7-second session measured 3.505 ms mean and 8.328 ms p99, with
102 samples over 8.333 ms and an 18.019 ms worst sample. The report showed no
invalid packets, discarded bytes, or sink retries, but did show 15 recovery
events and a 24.631 ms maximum USB-tethered network gap.

## Runtime note

The launcher uses the Microsoft Edge WebView2 runtime provided by supported
Windows 10/11 installations. It is not bundled into this lightweight release.

The Android APK is debug-signed for experimental testing.
