# Doritrack v0.5.0-alpha5 — overlapping keyboard taps

Keyboard mode now emits a fresh key-down when a new finger taps a lane already
held by another finger. Previously that tap only increased the lane's ownership
count and emitted no press. The existing hold stays asserted, and lifting either
finger cannot release the lane until its last owner lifts. Movement, heartbeats,
and submission retries do not repeat the new tap.

## Downloads

- Windows x64: extract `Doritrack-v0.5.0-alpha5-windows-x64.zip` and open
  `HolodoriUsbController.exe`.
- Android: `Doritrack-v0.5.0-alpha5-android.apk`, version code 30.
- Linux x64: extract `Doritrack-v0.5.0-alpha5-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`.

The overlap fix is in the host. The alpha4 APK remains protocol-compatible.

## Validation and limits

Regression tests cover overlapping taps, either lift order, retries, unchanged
snapshots, and rapid slide/lift/tap sequences across all six lanes with the same
or different fingers, including reordered and duplicate delivery.

Release validation covers native tests, strict Clippy, optimized builds,
Android unit tests, debug/release builds and lint, launcher frontend/Rust checks,
and V4/V5 loopback fault recovery against the 8.333 ms budget.

In-game recognition of an additional key-down on an already-held key remains
unverified: a game may treat it as a repeat. This release does not claim to fix
all rapid-tap misses or compressed release-to-press timing after delayed delivery.
Loopback checks simulate OS acceptance; physical USB/Wi-Fi gameplay soaks remain
pending. Keyboard mode is the current gameplay baseline; touch mode is a proof
of concept. This is an unofficial companion subject to the game's terms and
competitive rules.
