# Doritrack v0.5.1

Stable release of the v0.5.1 alpha series: lower-latency scheduling, optional
pressure calibration, and session diagnostics. Install the Windows and Android
apps from this same release.

- **Lower-latency scheduling.** Android 10 and newer requests Wi-Fi low-latency
  mode during V5 Wi-Fi pairing and play. Windows requests HighQoS alongside high
  input priority. The host sends fewer duplicate ACKs while loss recovery stays
  immediate.
- **Pressure calibration (optional, off by default).** In Android Preferences,
  calibrate a cutoff so light brushes do not press keys. An accepted finger
  stays registered until it lifts, and a lighter hold or slide is never
  released. Use a conservative cutoff, because some valid taps start lightly.
- **Session diagnostics (optional).** Enable **Diagnostics** before Start, then
  export the phone reports after Stop. The PC writes a readable summary and JSON
  to its report folder (Settings > Open report folder), and
  `tools/diagnostic_report.py` joins both sides. See `DIAGNOSTICS.md`.
- **Fix since alpha3:** an environment constraint that persists, such as Battery
  Saver or Wi-Fi without a low-latency lock on Android 9 and older, now opens
  one diagnostic incident instead of one every 2 seconds. Long sessions no
  longer fill the report before real faults are recorded. The phone summary
  counts constrained samples instead.
- The Windows ZIP contains only the PC app; download the Android APK separately.
  Windows reports now live in `%LOCALAPPDATA%\Doritrack\Logs`.
- Updated Android and Windows artwork, plus a privacy policy covering local
  controller data, pairing credentials, diagnostics, and the Wi-Fi lock
  permission.

## Downloads and upgrade

- Windows x64: extract `Doritrack-v0.5.1-windows-x64.zip` and run
  `HolodoriUsbController.exe`.
- Android: install `Doritrack-v0.5.1-android.apk`, version code 38. It updates
  v0.5.0 and the v0.5.1 alphas in place, keeping settings and pairing.

Install the phone and PC apps together before enabling pressure calibration;
older V5 hosts reject its keyboard-only contact flag.

Automated loopback testing kept healthy delivery and recovery after loss of
both immediate copies within the 8.333 ms design budget. These tests simulate
OS acceptance and do not establish latency on every phone, cable, router, PC,
or game input loop.

This is an unofficial companion for hololive Dreams, subject to the game's
terms and competitive rules.
