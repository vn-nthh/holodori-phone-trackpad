# Holodori USB-tethered UDP v0.4.1

This release hardens the driver-free USB-tethered controller, reduces work
on Android's touch path, and adds an opt-in local-only tethering mode.

## Highlights

- Every gameplay frame, discovery record, and acknowledgement has immediate
  redundant coverage, with a 2 ms replay path when both copies are lost.
- Android requests unbuffered pointer dispatch for the full play session and
  keeps locked play renderless except for the unlock control.
- Windows measures active liveness only after ordered input reaches the OS
  sink, then releases all injected input and requires a fresh session after a
  stalled or failed link.
- The launcher exposes six focused lane-key slots and reports a fixed UDP-port
  conflict before starting a second host.
- The optional local-only tethering setting prevents an Android/RNDIS adapter
  from becoming the PC's internet gateway while preserving the phone subnet.
  The launcher offers elevation when required, and the native host restores
  the original Windows route policy on a normal stop.

## Validation

- Native Rust formatting, 29 tests, strict Clippy, and optimized build passed.
- Android debug/release builds and debug/release lint passed.
- Tauri frontend production build, Rust tests, strict Clippy, and optimized
  Windows build passed.
- Legacy Python suite: 110 tests passed.
- Ten release-host loopback samples recovered a corrupt first copy through its
  immediate redundant copy in at most 0.087 ms. Ten simulated two-copy losses
  recovered through the 2 ms replay in at most 2.755 ms.

The Android APK remains debug-signed for experimental testing. The 8.333 ms
target still depends on the physical phone, cable, Windows scheduler, and
RNDIS path; a real-device soak is required before treating it as universal.
