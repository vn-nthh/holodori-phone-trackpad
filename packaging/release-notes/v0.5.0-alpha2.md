# Doritrack v0.5.0-alpha2 — experimental transport UI and USB recovery fixes

Wi-Fi/local-network mode now hides the legacy protocol checkbox and the entire
"Stop the PC from using the phone's internet" section. Both return when USB is
selected. Saved Linux USB tether settings no longer block Wi-Fi startup or get
sent as Wi-Fi session options.

This release also fixes Windows startup after unplugging a USB tether adapter.
Unavailable adapters leave cleanup pending with their recovery records intact.
Recovery checks the same adapter again before applying new local-only settings.
A reused process ID no longer blocks startup for an absent adapter; ownership
must still be verified before restoring a present adapter.

## Downloads

- Windows x64: extract `Doritrack-v0.5.0-alpha2-windows-x64.zip` and open
  `HolodoriUsbController.exe`.
- Linux x64: extract `Doritrack-v0.5.0-alpha2-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`.
- Android: `Doritrack-v0.5.0-alpha2-android.apk`, version code 27.

The existing v0.5.0-alpha1 Android app remains compatible; no phone update is
needed for these host-side fixes. The new APK is debug-signed for experimental
testing with a different key from the published alpha1 APK. Replacing that
installation requires uninstalling it first, which removes settings and pairing.
Keep the existing phone app to avoid that reset.

## Validation and limits

Release validation covers native tests, strict Clippy, optimized builds,
launcher frontend and Rust tests, Android debug/release builds and lint, and
the V4/V5 loopback fault checks against the 8.333 ms budget. Browser checks
verify both directions of USB/Wi-Fi option visibility. The Windows recovery
smoke test starts successfully with the existing missing-adapter records and
preserves both records byte-for-byte.

Loopback checks simulate final OS acceptance and do not establish physical
phone-to-game latency. Physical USB/Wi-Fi reconnection, Keystore device tests,
and long gameplay soaks remain untested for this patch. This is an unofficial
companion, subject to the game's terms and competitive rules.
