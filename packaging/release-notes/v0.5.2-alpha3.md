# Doritrack v0.5.2-alpha3 — Faster same-lane tap spacing, USB route recovery fix

Prerelease on top of v0.5.2-alpha2. Install the Windows and Android apps from
this same release. The Android app is unchanged apart from its version number.

## Separate fast same-lane taps (beta, off by default)

The option no longer waits a whole 60 Hz game frame. Same-lane key changes
that would otherwise reach Windows at the same instant are now spaced by a
fixed 2 ms instead of 17 ms:

- A re-press of a lane right after its release waits 2 ms.
- A finger landing on a lane another finger holds sends a release, then a
  press 2 ms later.
- A tap delivered in one burst after a network repair is held for 2 ms.
- Slides and taps on different lanes are still never delayed.

The most a tap can be delayed is now about 6 ms, down from about 51 ms, which
stays inside the 8.333 ms design budget. Please report whether fast same-lane
patterns register better with the option on or off.

## USB tether route recovery (Windows)

With **Don't use the phone's internet** on, the PC could fail to put the
phone's internet route back after play, reporting that the captured gateway
was no longer configured, and leave the recovery record behind. It now
confirms the gateway through the adapter's own configuration. A route from an
older tether session is skipped instead of brought back. Phones that change
their USB network address every tether session (such as Samsung) no longer
leave recovery records that can never complete.
