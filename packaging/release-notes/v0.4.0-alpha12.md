# v0.4.0-alpha12

This experimental bundle adds a normal Windows launcher for the USB-tethered
UDP host. Users can choose touch or keyboard mode, edit lane keys, keep the
120 Hz warning budget, and save latency reports without opening a terminal.

The report option remains enabled by default, matching the previous packaged
launchers. Metrics are diagnostic-only and are collected in memory during play;
the report is written when the user presses Stop.

Stopping through the launcher sends the host a graceful shutdown command so
held keyboard or touch input is released before the app closes.
