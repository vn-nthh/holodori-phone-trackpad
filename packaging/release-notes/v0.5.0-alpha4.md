# Doritrack v0.5.0-alpha4 — Android USB pairing fix

Fixes USB tether discovery on Android 15/16 devices that expose tethering as a
local Android Network. Previously the phone app excluded that interface as an
upstream network and immediately returned to Pair with "Enable Android USB
tethering and connect the cable", even when tethering was enabled. This matches
the reported Samsung S21 FE / One UI 8 / Android 16 failure.

The APK now recognizes an explicitly identified downstream USB network, binds
its socket to that exact network, and ends the session if the network identity
changes. Older phones retain conservative USB-interface discovery. Upstream
networks, VPNs, and ambiguous interfaces remain excluded.

## Downloads

- Android: `Doritrack-v0.5.0-alpha4-android.apk`, version code 29. Install this
  update on the affected phone. The experimental signing key matches alpha2/alpha3.
- Windows x64: extract `Doritrack-v0.5.0-alpha4-windows-x64.zip` and open
  `HolodoriUsbController.exe`.
- Linux x64: extract `Doritrack-v0.5.0-alpha4-linux-x64.tar.gz` and follow
  `Docs/LINUX_SETUP.md`.

Existing alpha3 hosts are compatible with the updated APK. An installation
using the different alpha1 signing key requires uninstalling before installing
this APK, which resets phone settings and pairing.

## Validation and limits

Release validation covers Android unit tests, debug/release builds and lint,
native tests, strict Clippy, optimized builds, launcher frontend/Rust checks,
and isolated V4/V5 loopback fault checks against the 8.333 ms budget.
Regression tests cover the newer Android USB-network exclusion bug, conflicting
upstream interfaces, and the older-phone discovery fallback.

Physical S21 FE verification and USB/Wi-Fi gameplay soaks remain pending.
Loopback checks simulate OS input acceptance and do not establish physical
phone-to-game latency. This release does not change touch scheduling or add
charging controls. This is an unofficial companion, subject to the game's
terms and competitive rules.
