# Doritrack

Android スマホを、Windows 上の [hololive Dreams (holodori)](https://store.steampowered.com/app/4282500/hololive_Dreams/) 向け 6 レーン・タッチコントローラーとして使えます。

スマホでタップ、ホールド、スライド、同時押しができます。Windows アプリがそれらのタッチをレーン用キーに変換します。デフォルトのキーは `S D F J K L` です。

> これは非公式のコミュニティ製ツールです。COVER Corp.、hololive production、QualiArts とは一切関係ありません。

必要なもの:

- Windows 10 または 11 の PC
- Android スマホ
- USB テザリングとデータ通信対応ケーブル、またはスマホが Wi-Fi 接続された同じプライベート LAN

## クイックスタート

1. Windows アプリをダウンロードして解凍します。
2. Android に APK をインストールします。
3. USB の場合はデータケーブルで接続し、スマホの **USB テザリング** をオンにします。Wi-Fi の場合は両方の端末を同じプライベート LAN に接続します。
4. `HolodoriUsbController.exe` を開いて管理者権限を許可し、スマホでも Doritrack を開きます。
5. 両方で同じ接続方法を選びます。
6. 初回は両方で **Pair** を押します。PC に表示される 8 つの番号のレーンをスマホで順にタップし、**Pattern matched** を確認してから PC で **Approve** を押します。次回からペアリングは記憶されます。
7. 必要なら **Preferences** でレーンキーを変更し、両方で **Start** を押します。
8. プレイエリアを調整してロックするか親指モードを選び、ゲームを開始します。
9. 終わったら **Stop** を押します。

USB テザリングの設定名と場所は機種によって違います。だいたい **ネットワーク**、**接続**、**ホットスポット**、**テザリング** のいずれかの下にあります。

## できること

- タップは短いキー入力になります。
- ホールドは指を離すまで押し続けます。指がプレイエリアの少し外へ
  移動しても、最寄りの端のレーンを保持します。
- スライドは通過したレーンを順に入力します。
- 複数の指で別レーンを同時にホールドできます。
- 切断時は押しっぱなしのキーを解放するので、キーが固まりません。
- レーンキーは Windows アプリで変更できます。

## 接続の仕組み

USB テザリングがスマホと PC のあいだに小さなネットワークを作ります。Android アプリはそのリンク上で UDP を使ってタッチ更新を送ります。USB デバッグ、root、専用の USB ドライバは不要です。Wi-Fi を選ぶと、同じプライベート LAN を利用できます。Pair と Start は選択した接続方法だけを使います。

各更新には番号が付き、破損も検査されます。重要な更新はすぐ 2 回送られます。両方落ちた場合、スマホは約 2 ミリ秒後に再送します。PC は Windows がキーまたはタッチ操作を受け付けたあとだけ、更新を確認します。

アプリはすべての指の状態を保持します。ホールド、同時押し、速いスライドを維持でき、短い再接続のあともホールドを安全に復元できます。切断後の古いタッチは捨てるので、遅れて再生されません。

このツールは通常の Windows 入力を送ります。ゲームのプロセスを開いたり、読んだり、変更したりはしません。

プロトコル V5 はペアリングした端末を認証し、入力を暗号化します。初回のレーンパターン照合と PC 側の承認が必要です。信頼できる PC を使い、ファイアウォールでは選択した USB またはプライベート LAN でのみ接続を許可してください。UDP ポート `42825` を公衆ネットワークへ公開しないでください。認証のない旧プロトコル v4 は、明示的なレガシー USB オプションでのみ使えます。

## Windows のオプション

### レーンキー

各キー枠を選んで、使いたい文字または数字を押します。デフォルトは `S D F J K L` です。

ゲームを開く前に、メモ帳でカスタムキーを試してください。Windows ランチャーは起動時に管理者権限を求めるため、管理者として動くゲームにも入力できます。

### PC がスマホのインターネットを使わないようにする

USB テザリングだと、PC がスマホをインターネット接続として使うことがあります。スマホと PC のローカル接続だけ欲しいときは **Stop the PC from using the phone's internet** をオンにしてください。

ランチャーは起動時に管理者権限を求めます。Stop すると元のネットワーク設定に戻ります。ルート変更前に復旧用スナップショットも保存するため、異常終了した場合は次回起動時に復元します。

ルート保護は、スマホが確認済みのテザリング用インターフェイス上で検出されてから開始します。復旧時は、Windows またはユーザーが後から追加した新しいルートを保持し、古いスナップショットのゲートウェイで置き換えません。クリーンアップ完了前に対象のテザーアダプターが取り外された場合、復旧スナップショットは保持されます。同じアダプターを再接続すると、ランチャーが所有していた設定の復元を完了できます。

ステータス欄には **Waiting**、**Phone connected**、**Recovering**、**Stopping** が表示されます。**Recovering** では押下中の入力をすでに解放し、新しいスマホセッションを待っています。もう一度 **Start** を押す必要はありません。

### 停止時にレイテンシレポートを保存する

プレイ後にレポートが欲しい場合はこのチェックを付けたままにしてください。**Stop** を押すと `Windows\Logs` に保存されます。プレイ中はレポートを書きません。

## トラブルシューティング

### スマホが接続できない

- 充電専用ではなく、データ通信対応のケーブルか確認してください。
- USB テザリングをいったんオフにして、もう一度オンにしてください。
- Windows が新しい Ethernet または USB ネットワーク接続を作るまで待ってください。
- 両方で同じ接続方法を選び、ペアリング後に両方で **Start** を押してください。
- Wi-Fi の場合は同じサブネットを使い、ルーターが端末間通信を許可しているか確認してください。
- Windows ファイアウォールで `holodori-native-host.exe` の UDP ポート `42825` を許可してください。
- コントローラーの二重起動をやめてください。ポート `42825` を使えるのは 1 つだけです。

### Windows アプリが開かない

ランチャーは Microsoft Edge WebView2 を使います。Windows 10 / 11 には通常入っています。起動したまま閉じる場合は、WebView2 Runtime をインストールまたは更新してください。

### ゲームの外ではキーが効くが、ゲーム内では効かない

ゲームを管理者として動かしている場合は、コントローラーも管理者として再起動してください。

### Android が APK のインストールを拒否する

旧リリースとは署名鍵が異なります。古い Holodori コントローラーアプリを一度アンインストールし、v0.5.0 をインストールして再ペアリングしてください。スマホ側の設定とペアリングは消去されます。

## 開発者向け

ライブ入力経路は、ネイティブの Rust ホスト、Android アプリ、小さな Tauri ランチャーで構成されています。プロトコルは 120 Hz プレイ向けの 8.333 ms フレーム予算を前提に設計していますが、実測はスマホ、ケーブル、PC に依存します。

リリース用バンドルは PowerShell からビルドします。

先に [Android のリリース署名鍵](packaging/ANDROID_SIGNING.md)を設定してください。

```powershell
.\packaging\build-experimental.ps1 `
  -CargoHome "$env:USERPROFILE\.cargo" `
  -JavaHome $env:JAVA_HOME `
  -AndroidSdk $env:ANDROID_SDK_ROOT
```

ネイティブテストの実行:

```powershell
cargo test --manifest-path native-host\Cargo.toml --all-targets
```

現在のソースブランチの実装は [アーキテクチャガイド](EXPERIMENTAL_ARCHITECTURE.md)、[プロトコル v5 仕様](PROTOCOL_V5.md)、[相互運用テストベクター](PROTOCOL_V5_TEST_VECTORS.md) を参照してください。[プロトコル v4 仕様](PROTOCOL_V4.md) は公開済み v0.4.1 と明示的なレガシー USB モードの移行資料です。
